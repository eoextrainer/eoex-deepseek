EOEX Platform AI Prompt for Development
Project Overview
EOEX Platform - A multi-tiered subscription-based community platform with Netflix-style UI for users, Salesforce-style admin interfaces, and Disney+ inspired workspace design.

Technical Stack Requirements
Frontend: React/Vue.js SPA with WebGL/Three.js for 3D elements

Backend: Python (FastAPI/Django) with PostgreSQL

Authentication: JWT/OAuth2 with role-based access control

Real-time: WebSockets for chat and notifications

Deployment: Docker containers with CI/CD pipeline

Testing: Pytest (backend), Jest/Cypress (frontend)

Monitoring: ELK stack or Grafana/Prometheus
